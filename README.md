# SolidityJolt

SolidityJolt enables real-time smart contract execution on a blockchain-based platform with decentralized storage integration within a modular framework.

SolidityJolt is built to be simple and practical, focusing on doing one thing well.

**Why SolidityJolt?**

- SolidityJolt enables real-time smart contract
- execution on a blockchain-based platform
- with decentralized storage integration within

- python

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/SolidityJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
